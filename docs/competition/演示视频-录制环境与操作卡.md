# 现场扫描演示录制操作卡

## 起始状态

- 系统地址：`http://127.0.0.1:3000`
- 本机管理员账号：`admin / admin`
- DVWA：`http://dvwa.test/`，实验账号 `admin / password`
- WebGoat：`http://webgoat.test/`
- OpenVAS：内部 `openvas:9390`，当前 GMP 22.7 可用
- 13 个外部工具和 OAST 当前均可用

录制从登录页开始，不使用历史任务作为本次扫描结果。

| 字段 | 填写内容 |

| 目标 | `http://dvwa.test/` |
| 登录方式 | 账号登录 |

页面当前没有执行时长输入项。任务会持续到工具完成或用户手动取消。

## 分段录制

### 第一段

1. 登录页输入管理员账号并进入总览。
2. 进入“新建扫描”。
3. 按上表填写。
4. 勾选授权确认。
5. 点击“开始安全扫描”。
6. 在新任务页录制 20-40 秒实时节点运行。
7. 停止录屏，但不要关闭任务页面。

### 等待阶段

- 等任务状态显示“已完成”。
- 不修改配置，不重启服务。
- 记录新任务 ID 和最终 Finding、风险组数量。

### 第二段

1. 回到同一个任务页。
2. 录制最终指标、实际工具顺序和 AI 决策。
3. 展开最高严重度风险组和证据哈希。
4. 打开报告页，展示 `Time limit: none`。
5. 进入历史页，展示资产快照。
6. 回到任务页，讲创新点，切片尾。

## 剪辑规范

- 扫描等待段可以跳切或 4 倍速。
- 跳切前显示一行字幕：“扫描持续运行中，等待段已剪辑”。
- 第二段必须保留与第一段相同的 Task ID。
- 不把历史任务数据剪入本次扫描。
- 如果本次结果为 0，如实说明当前策略未命中，不使用旧结果替换。

## 隐私和安全

- 不点击 AI 设置中的“显示 API Key”。
- 不展示 `.env`、Cookie、Token 或授权文件。
- 不展示其他浏览器标签页。
- 不扫描公网目标。
- 浏览器保持 100% 缩放并使用 F11 全屏。
