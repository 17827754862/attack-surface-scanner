# 5-8 分钟演示视频脚本与分镜

## 录制规格

| 项目 | 要求 |
|---|---|
| 格式 | MP4 / H.264 |
| 分辨率 | 1920×1080 或更高 |
| 帧率 | 30 fps |
| 语言 | 普通话 |
| 时长 | 建议 7 分钟 |
| 字幕 | 中文，必须校对 |
| 画面 | 浏览器全屏，鼠标操作清晰可见 |

## 0:00-0:35 项目介绍

画面：安全态势总览，展示产品名称、资产指标、扫描引擎状态和实时数据流。

讲解：

> 本作品是攻击面侦察与漏洞定位系统，面向自有资产和明确授权目标。它把资产发现、端口识别、Web 扫描、API 检查、密钥扫描和主机漏洞扫描统一到一个任务中，并通过证据文件、风险组和报告形成可复核闭环。

## 0:35-1:30 新建扫描与授权门禁

画面：进入“新建扫描”，展示目标、认证配置、模式、工具组合、时间预算和速度上限。停留在风险声明与授权复选框。

操作：

1. 填写 `http://dvwa`。
2. 选择认证档案。
3. 选择 `standard`、`active`、`full_agent`、`safe`。
4. 勾选授权确认。

讲解：

> 每次主动扫描都必须确认目标归属或明确授权。系统还会在后端重新检查 scope、DNS 解析和 CIDR，避免只依赖前端勾选。最大请求速率限制为每秒 5 次。

## 1:30-2:20 AI 动态编排

画面：AI 设置页，展示 OpenAI 兼容接口、模型配置、密钥状态和动态编排说明。

讲解：

> AI 不负责生成扫描命令。系统先按授权、模式、工具组合和资产条件生成候选工具，再让模型根据前一个扫描器的 Finding、端点、错误和摘要选择下一个工具。模型只能返回候选节点或结束。

画面：切到任务详情，指出 AI Router 节点和“AI 选择 92% / 88%”决策标签。

讲解：

> 如果模型未配置、超时或返回非法节点，系统自动回退固定安全顺序，扫描主链路不会中断。每次选择都会写入 scan_decisions，包含来源、理由和置信度。

## 2:20-3:40 真实数据流

画面：任务详情页纵向数据流，向下滚动展示资产发现、HTTP 探测、端口扫描、AI Router、ZAP、Nuclei 和主动验证。

讲解：

> 任务页不再固定铺开全部节点。只有已经进入执行链的工具才会出现，箭头表示前序数据传给下一步。未使用工具只显示汇总数量，因此评审可以直接看到这次任务实际用了什么工具。

画面：指出工具名称、状态、数据摘要和 AI 决策标签。

## 3:40-4:40 风险组、Finding 与证据

画面：展开风险组，展示实例数、URL 数、来源工具、重放验证、误报检查、修复和复测建议。切换到 Finding 列表，展示 evidence hash。

讲解：

> 不同工具的原始结果先归一化为 Finding，再按主机、端口和风险类型去重。多来源命中会保留在 also_reported_by 中。报告下载证据文件前会重新计算 SHA-256，防止文件错配或被误改。

## 4:40-5:35 报告与工作流

画面：进入报告页，展示遮罩工作流、风险摘要、节点状态、Finding 和报告详情。点击下载 JSON 或 Mermaid 源。

讲解：

> 报告支持 HTML、JSON、Mermaid 和 PNG。工作流按实际执行轨迹生成。PNG 渲染不可用时，前端会使用本地 Mermaid 包兜底，不依赖在线服务。

## 5:35-6:20 历史、恢复与安全降级

画面：历史与资产页，展示扫描快照和风险变化。回到任务详情，指出取消与从断点恢复按钮。可在测试环境演示一次 AI 关闭或模型不可用后的固定流程。

讲解：

> 系统保存资产快照和 LangGraph checkpoint。取消后会终止扫描子进程，失败或取消任务可以从断点继续，不必重跑全部扫描器。无模型时自动使用固定流程。

## 6:20-7:00 技术亮点与总结

画面：展示技术文档中的 AI Router 和创新点页面，或回到总览页。

讲解：

> 本项目的核心创新是把 AI 决策放进确定性安全边界：模型只选择候选工具，不生成命令、不增加目标、不绕过授权门禁。系统通过多引擎融合、证据哈希、动态数据流和断点恢复，提高了扫描流程的可观察性、可复核性和可维护性。

结束画面：

> 团队名称 / 学校 / 成员
> 谢谢评审老师

## 录制检查清单

- 视频时长在 5 到 8 分钟之间。
- 分辨率不低于 1920×1080。
- 普通话清晰，字幕与画面一致。
- 不出现真实 API Key、Cookie、密码和个人身份信息。
- 不展示未授权真实目标。
- 关键操作窗口留出 1 到 2 秒，避免鼠标移动过快。
- 导出后检查音画同步、文件可播放和字幕烧录。
